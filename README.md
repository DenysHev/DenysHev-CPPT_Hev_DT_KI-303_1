# Лабораторна робота №2
## Предметна модель складу автозапчастин
**Курс:** Кросплатформні засоби програмування
**Робота:** №2
**Варіант:** 4 — Склад автозапчастин
**Мова:** Java 21
**Система збірки:** Maven

## Опис
Програма читає список автозапчастин зі складу, перевіряє кожен запис, обчислює показники та формує звіт у консоль і текстовий файл. Невалідні рядки не зупиняють програму: для кожного з них виводиться номер рядка та причина пропуску.

Предметна сутність `AutoPart` реалізована як незмінний клас із
інкапсульованим станом. Її конструктор перевіряє доменні правила під час
створення об'єкта: обов'язкові текстові поля не можуть бути порожніми, запас і
ціна не можуть бути від'ємними, а ціна має бути скінченним числом.

Набір обчислених показників представлений record `InventoryMetrics`. Формат
вхідного CSV і зовнішній текстовий звіт збережені сумісними з попередньою
роботою.

## Формат запису
Кожен рядок вхідного файлу має 5 полів, розділених крапкою з комою `;`:

    sku;name;stock;unitPrice;supplier

де:
- `sku` — артикул деталі (текст, обов'язкове поле)
- `name` — назва деталі (текст, обов'язкове поле)
- `stock` — кількість на складі (ціле число, не від'ємне)
- `unitPrice` — ціна за одиницю (число з крапкою, не від'ємне)
- `supplier` — постачальник (текст, обов'язкове поле)

Файл кодують у UTF-8.

## Показники варіанта 4
1. Кількість коректних записів
2. Загальна кількість деталей (сума `stock`)
3. Вартість запасу (сума `stock * unitPrice`)
4. Найдорожча деталь (максимум `unitPrice`)

## Приклад вхідних даних
Файл `data/input.csv`:

    SKU-001;Гальмівна колодка;50;450.00;Bosch
    SKU-002;Масляний фільтр;120;180.50;Mann
    SKU-003;Амортизатор;30;1250.00;KYB
    SKU-004;Свічка запалювання;200;95.75;NGK
    ;Порожній SKU;10;100.00;Test
    SKU-006;Неправильна ціна;20;abc;Test
    SKU-007;Від'ємний запас;-5;200.00;Test
    SKU-008;Мало полів;10;100.00

Перші 4 рядки — коректні. Рядки 5–8 хибні та будуть пропущені з поясненням.

## Збірка та запуск
Перевірка (компіляція → тести → SpotBugs):

    ./mvnw -B clean verify

Windows:

    mvnw.cmd -B clean verify

Збирання executable JAR:

    ./mvnw -B package

Запуск:

    java -jar target/cppt-labs.jar --input data/input.csv

Запис звіту у файл:

    java -jar target/cppt-labs.jar --input data/input.csv --output out/report.txt

Довідка:

    java -jar target/cppt-labs.jar --help

Версія:

    java -jar target/cppt-labs.jar --version

## Параметри командного рядка
- `--help` — показати довідку
- `--version` — показати версію
- `--input FILE` — шлях до вхідного CSV (типово `data/input.csv`)
- `--output FILE` — шлях до файлу звіту (типово `out/report.txt`)

## Тестування
Запуск JUnit-тестів:

    ./mvnw -B test

Перевіряються:
- коректний рядок → об'єкт AutoPart
- валідація доменних правил під час створення AutoPart
- порожній рядок
- неправильна кількість полів
- нечислове значення в числовому полі
- від'ємне значення
- порожнє обов'язкове поле
- ситуація, коли всі записи невалідні (без ділення на нуль)

## Статичний аналіз
SpotBugs запускається у фазі `verify`:

    ./mvnw -B verify
